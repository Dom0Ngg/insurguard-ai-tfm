# InsurGuard AI - TFM

Plataforma multiagente para la detección inteligente de fraude y análisis automatizado de siniestros en el sector asegurador.

## Objetivo del proyecto

El objetivo es desarrollar un prototipo funcional basado en Inteligencia Artificial que permita analizar siniestros, extraer información documental, consultar coberturas mediante RAG, detectar posibles indicios de fraude y generar explicaciones para los analistas.

## Componentes principales

- OCR y extracción documental
- Sistema RAG para consulta de pólizas y coberturas
- Arquitectura multiagente
- Modelo de Machine Learning para detección de fraude
- Score de riesgo
- Explicabilidad
- Monitorización y MLOps
- Interfaz web para análisis de siniestros

## Estructura del repositorio

- `backend/`: API, agentes, RAG, OCR y modelo ML
- `frontend/`: interfaz de usuario
- `data/`: datasets y documentos de prueba
- `notebooks/`: análisis exploratorio y entrenamiento de modelos
- `docs/`: documentación técnica y diagramas
- `mlops/`: experimentos, monitorización y versionado
- `tests/`: pruebas del sistema
